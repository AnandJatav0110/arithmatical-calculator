# 🧮 Calculator App

A simple and elegant calculator built using **HTML, CSS, and JavaScript**. This project features a modern neumorphic UI design with basic arithmetic operations.

## 📸 Preview

![Calculator Preview](./assets/calculator-preview.png)

## ✨ Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 📊 Percentage calculations
- 🗑️ Clear all functionality (AC)
- ⌫ Delete last digit
- 🔢 Decimal number support
- 🎨 Modern neumorphic design
- 📱 Responsive layout

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/your-username/calculator.git
```

### 2. Navigate to the project directory

```bash
cd calculator
```

### 3. Open the project

Simply open the `index.html` file in your browser.

## 🎯 Calculator Buttons

| Button | Function |
|----------|-----------|
| AC | Clears the entire display |
| DEL | Deletes the last entered character |
| % | Percentage operation |
| / | Division |
| * | Multiplication |
| - | Subtraction |
| + | Addition |
| = | Calculates the result |
| . | Decimal point |
